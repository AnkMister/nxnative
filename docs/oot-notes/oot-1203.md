## Merge and deviations

Applied the feature commit without committing its original message. Resolved
conflicts by preserving Ocarina's `reg_bump(id_, 1)` sampler invalidation
instead of restoring the old global `g_reg_gen++`, preserving NVN2's high
vertex attributes and their key layout, retaining `decode_ubo_img` in the
border tests, and keeping both games' finding links. Regenerated the chain
header rather than taking either conflicting generated value.

The feature is Python-generated MSL plus Objective-C host selection. No
translator source, dependency, lock-file or binary change was needed. No
bundled executable or DLL was run. No packages were installed; NuGet cooldown
checks and a translator rebuild are therefore not applicable to this port.

Default-off control added: `DM_NVN_BORDER_SPLIT=1` selects ordinary `_b`
libraries unless a bound sampler requires correction. Unset, `0`, or any
other value selects `_bb` for all ordinary shaders that advertise it. This
keeps correction code present for baseline A/B, using the same rebuilt assets
and host. The switch is read once per host thread; restart between variants.
Alpha-test and logic-operation libraries retain correction in both modes.

Two upstream edge cases were tightened: stale `_bb` is removed even when the
shared alpha/logic compile succeeds; failure to compile the required correcting
fallback fails that shader's build rather than publishing a plain shader with
no correcting twin. Added orchestration tests for these paths. The runtime
switch cache is thread-local to avoid a new race in background PSO compilation.

## Validation and remaining gates

Validation logs live under
`${OOT_SHARED_CONTEXT}/setup/scratch/1203-*.log`.
The final counts are recorded below after completion.

No game, regress.py, full shader build, device install, or baseline write was
performed. Native tests exercise this port's compiled NVN host code on the M4
Max. A full shader rebuild, Ocarina visual checks and GPU/energy measurement
remain required. Cross-game regression is also unrun under the shared context's
explicit restriction. The upstream M1 figures describe other games and are not
predictions for this M4 Max.

Risk: dynamic sampler binds must invalidate the current PSO when the border
key changes. The port retains the upstream per-draw comparison and resolves
samplers through the same binding kinds as argument encoding. Pipeline-key
logic operation checks now test bit 0, so bit 1 cannot disable blending or
dual-source selection. Missing or incompatible `_bb` at runtime still follows
the upstream red-log fallback to the nearest Metal colour. Test visual border
cases as well as ordinary scenes; alpha/logic/specialized fragment paths may
receive no optimization. Disk footprint and first-use PSO compilation can grow.
